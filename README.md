📊 Smart Stock Analysis Dashboard

🚀 Live App: https://smart-stock-analysis-sicgxfiplpayjqbnynkvls.streamlit.app/

---

📌 Overview

AI-powered stock analysis dashboard for **2000+ NSE stocks** with prediction, sentiment analysis, and interactive charts.

---

🔥 Features

* 🔍 Smart stock search (like Groww)
* 📈 Interactive stock charts
* 🤖 AI-based price prediction
* 📊 Buy/Sell signals
* 📰 News sentiment analysis
* 🎨 Clean dashboard UI

---

🛠️ Tech Stack

* Python
* Streamlit
* Pandas & NumPy
* Scikit-learn
* Plotly
* yFinance API
* News API

---

⚙️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
